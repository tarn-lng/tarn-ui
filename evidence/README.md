# Informes históricos

Esta carpeta conserva explicaciones escritas de ejecuciones anteriores. Solo los
archivos Markdown se publican. Los registros, parches, hashes, diagnósticos JSON,
capturas y otros resultados crudos citados por esos informes son archivos locales
ignorados por Git.

Los resultados actuales de fase 2 están en
[docs/phase2-results.md](../docs/phase2-results.md). Las nuevas ejecuciones generan
sus archivos en `.build/evidence/`; no es necesario añadirlos al repositorio.
